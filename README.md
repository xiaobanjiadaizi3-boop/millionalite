# millionalite

「大富豪 × ローグライト」のブラウザカードゲーム。

- `index.html` … ゲーム本体（HTML / CSS / JS を単一ファイルに同梱、外部ライブラリなし）
- `SPEC.md` … ルールブックと開発フェーズの仕様書

## 遊び方（開発中）

`index.html` をブラウザで開くだけ。ビルド不要、GitHub Pages でそのまま公開できる。
